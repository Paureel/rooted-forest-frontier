## Reading the archive

Read the nearest README and exact manifest before using a result. A historical
file may call its own checkpoint current; a later counterexample or review can
supersede it. Imported files retain their original wording and hashes, including
failed and provisional assertions. Large omitted inputs can prevent a complete
replay from a clone; consult docs/large-files.md before asserting reproducibility.

To change the accepted project status, add a versioned review identifying the
exact sources, full consumer hypotheses, executed evidence, independent review,
and remaining assumptions. Maintainer integration and scientific acceptance
