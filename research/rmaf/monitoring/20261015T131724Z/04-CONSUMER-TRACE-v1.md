# Original agreement and callback interfaces

The exported local result concerns original agreement forests refining three checked source parents. Every use below keeps the original target and source labels, the global budget q=number of final blocks minus1, and the actual callback target/source-list/budget. The source code cited here is the isolated copy of the exact released payload; SOURCE-MAP-v1 binds each file to its release hash.

| Use | Required premises | Derivation and actual consumer |
|---|---|---|
| Original input | S,T proper binary trees with equal distinct natural labels; nonempty checked P=[A,B,C]; source embeddings disjoint | Explicit hs,ht,same,hp,hsource in PlanCover.solvePair_conditional_cover. No rho label or implicit marked root. Nonconsecutive natural labels are allowed; negative labels remain representation tests outside Nat. |
| Actual graph case | Actual PairGeometry.choose returns the specified binary edge; A/B bad, C good; C clears both target parent hulls | All appear in final coverage/mass signatures. ROOT8 fails this case because choose returns vertex00. Proper C-overlap boundary selects edge(0,01) but fails C clearance, so its theorem domain fails without a runtime-refusal inference. |
| Original-F ownership | F is an original target/source AF refining P | Crossing.crossing_occupies puts an edge-crossing final block in the original target hull. Two different parent blocks cannot both occupy the same edge vertex because F target embeddings are disjoint. original_binary_parent_mono derives one monochromatic parent family. No source-only agreement or target-Q agreement replaces F. |
| Literal source coverage | Original partition, source embeddings, parent containment and derived monochromaticity | CoreCover.side_core_cover invokes tagged whole-source coverage. selected_binary_core_cover returns membership in the actual ordered concatenation of two literal lists and an OutputWitness, including F refinement and original source realization. |
| Cached planner lists | Rank4, actual two q3 probes, exact accepted singleton stability | FourProbe.optimized_four_exact, PlannerFacts.reuse_exact and PlannerSources.plan_sources bind every retained entry to the same full source lists. No favorable target-output filtering occurs. |
| Global versus residual budget | F refines generated Q; original cost F.length-1<=q | generated_residual_budget uses Q.length=sourceCuts.length+1 and F.length>=Q.length. Therefore sourceCuts.length+(F.length-Q.length)<=q. Fixed parent cuts occur inside this identity exactly once. Entry guards precede Nat subtraction. |
| Ordinary child | Q is a checked source partition with source AND target Q embeddings disjoint | selected_cheap_facts derives both embedding checks for the cheap literal output.
