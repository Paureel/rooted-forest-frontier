## Disjoint local query budgets, including p=1

For each parent i run an exact constant-depth1 pretest on the actual tree
pair. Set ell_i=r_i in{0,1} on success, else ell_i=2. A failed-depth1 parent
is called at q_i=q-sum_{j!=i}ell_j; negative q_i fails immediately. The
other-component sum excludes i. Add all exact returned minima, then reject
if their sum exceeds q and combine witnesses otherwise.

If p=1 unresolved parent and at least one OTHER parent is bad, the one call
has q_i<=q-1. If that other-parent premise fails, q_i may equal q and only
a strict smaller-input rank can justify termination; no cut decrease is
claimed. If p>=2, each of the p calls has q_i<=q-2(p-1). The asymptotic
mass p*c^(-2(p-1))<=1/c for c>=2 is conditional on those actual local calls
and cost lower bounds. Polynomial pretests are charged at every state.
