# Frozen actual guarded caller

Every immutable file in COMMON-SPLIT-CALLER-MANIFEST-v1.json is frozen. No
further writes will occur to those files. Repairs need a new versioned
companion/package and new evidence, preserving this checkpoint.

Future source applicability/Setup construction, operation accounting and whole
solver assembly belong in separate directories and new result directories.
They are excluded from this release. The mutable top-level algorithm workfile
and progress card are also excluded. Derived .olean/.ilean/.pyc files and
__pycache__ may be recreated without changing scientific source bytes.
