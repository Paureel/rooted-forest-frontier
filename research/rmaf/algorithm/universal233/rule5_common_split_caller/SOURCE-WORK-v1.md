# Source work: explicit scope and remaining bridge

This release has kernel statements for actual job budgets/properness/decrease,
their rational list mass and the FULL candidate count, including failed owner
guesses and duplicate forest values. It has no machine-checked fine-operation
meter or complete source-runtime theorem. Candidate count alone is insufficient
to infer one.

The concrete source performs two outside depth01 tests (ordinary and marked),
at most two actual q-1 recursive callback invocations, explicit marker extension
when required, relabelling of actual reply lists, Cartesian owner guessing,
filter/erase, list materialization, original agreement checks, minimum selection
and a final cost/budget check. Full source accounting must include every one.
The Setup input's restriction/marked construction and source-case selector
must also be paid at their actual consuming call; they are not free work.

For a conventional source-level polynomial argument, let N include all input
tree nodes, actual callback reply list cells/labels and maximum address length;
label and budget arithmetic have a separate bit factor B. Actual AF replies
have bounded total label payload, but arbitrary untrusted callback payloads
cannot silently receive the same bound. The source Cartesian list has exactly
|FM|*|FN| candidates. Each candidate copies filter outputs and erase remainders;
its left append and list materialization must be charged even if its original
agreement check fails. List equality inside erase may scan full blocks.

The original checker recomputes leaves, flatten/count/membership, restrictions,
rootedSpan/minimalVertices and pairwise disjointness. Minimal-embedding address
lists retain full original paths. Pairwise embedding checks repeat these
computations for each block pair. The rooted labelled sameShape recursion can
visit Cartesian pairs of tree nodes, so treating it as one constant primitive
would be invalid. These are finite tree/list loops under the stated model,
but no numeric source envelope is accepted merely from a Nat arithmetic sum.

A conservative polynomial bound should follow by bounding these actual loops
and the reviewed depth01 implementation under the same primitive/bit model.
That consuming source-operation correspondence and the complete mutual solver
recurrence remain OPEN here, for independent cost review and later assembly.
This package claims no extracted instruction theorem or runtime base.

Final-cut recovery is not executed by this AF subroutine. The full solver must
bind one postselection recovery to its final original AF; any retained recovery
cost is separately paid once. Its formal exponential envelope cannot be
charged as a polynomial toll at every local recursive node.
