# Source selectors and paid canonical budgets

The new local implementations close the common X/Y selector and first-representative equations and give a paid canonical-budget variant at the actual raw, scheduler, concrete generator, and recursive callback sites. The old padded variant remains frozen with its D gap open.

`commonSelectorsBits` constructs X from the selected source subtree. It constructs Y by scanning the exact original pendant addresses, flattening their subtree labels, filtering the original source leaves, then appending a copied c. It copies each first representative, including source headD 0 behavior for empty selectors. `commonSelectedPayload_source_site` projects all eight payload operands and both fresh markers to the fields of the actual successful checked builder. `commonSelectedPayload_checked_step` puts any two selected present operands into the existing `OrientedStep`. The local classifier must supply its stored c with decoded value bad.c and actual source-leaf provenance; this package does not implement that classifier.

`trimBudget` inspects only finite little-endian bits, removes high zero padding, and charges exactly 8 times the input length plus 1. Its output has the same decoded value, never increases input length, and has length at most the decoded value. This conservative polynomial bound suffices here. Initial stored width Bq remains explicit in the first trim bill; initial label padding B remains separate from semantic label size L. Q may exceed the reduced leaf count. The ordinary caller specializes Q to k−1, without an implicit root marker.

`rawParentCanonical`, `generatedRawParentCanonical`, `scheduleCanonical`, and `generateCanonical` retain the existing producers and insert explicit finite trim boundaries. Under the same typed recursive refinement, their projected results equal the mathematical source, including list order, duplicates, guards, and refusal. `raw_payment_site` and `scheduler_allocation_site` identify the actual arrays passed to underlying callbacks with `subtractCanonical` and `allocationCanonical` outputs. `canonical_lineage` proves value nonincrease and stored width at most the original decoded Q for arbitrarily many such events. It does not identify events with ordinary depth. The actual generator fuel decrement preserves its initialized width with floor 1. The completed disjoint-job allocation can temporarily use at most Q+4N+3 bits before its callback trim.

Every reached callback trim adds 8 times that actual incoming array length plus 5. The raw ledger splits underlying solver work from the exact sum of reached trim fees. It retains rejected occurrences and duplicates in the guard/list bill. The scheduler ledger counts the actual reached hard callbacks, including the refusing one, and excludes later unexecuted callbacks. The concrete generated-parent equation retains its actual generator and checker bills. Selector work is bounded by explicit polynomials `commonSelectorsFee N B` and `commonSelectedPayloadFee N B`; all scans, copied labels, addresses, comparisons, appends, and constructed fields are charged.
