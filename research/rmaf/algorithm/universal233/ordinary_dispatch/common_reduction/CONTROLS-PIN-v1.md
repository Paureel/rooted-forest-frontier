# Executable controls pinned before compilation

The wrapper uses the actual depth-zero/one pretest as a bounded callback. On identical four-label trees with common cherry (0,1), budget 0 must expand to a valid original one-block agreement forest. On five-label trees whose common (0,1) cherry is unchanged while the other three labels have conflicting rooted topology, budget 0 must return none and budget 1 must return a valid original two-block forest. The selected cherry has zero actual original pendant cuts in both cases. The contracted five-label target has exactly four labels.

The kernel must reject the contrary claim of a returned forest at budget 0 in the conflicting fixture, and it must reject unchanged target label count after contraction. These are controls of the literal wrapper and strict progress, not a proof that the callback is universally exact.
