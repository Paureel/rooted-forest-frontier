# Source-pool nonproof producer compatibility

Before pooling differently versioned source modules, test whether the audit
distinguishes same-name, same-type definitions with different values. A
standard-axiom-only report must not be treated as value compatibility.

Predeclare separate clean twins, disagreeing values in both import orders,
and theorem-only proof variation. Test actual stored declarations before name
coalescence. A scientific source pool must reject any disagreeing nonproof
definition or use a documented isolated/adapted interface. No frozen source
or old result may be changed. This is author instrument development.
