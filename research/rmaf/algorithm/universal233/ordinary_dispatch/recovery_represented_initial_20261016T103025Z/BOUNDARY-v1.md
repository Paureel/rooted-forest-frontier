# Consumer boundary

Adoptable author-level interfaces:

- represented_initialization (RIInterface): exact frozen source initializer value and direct original stored input polynomial work, with W/count-width premises displayed.
- initializeBits_refused: exactly source duplicate-label refusal, including unequal bit arrays encoding the same label.
- initializeBits_output_words/initializeBits_retained_cells: returned representation widths and retained result cells.
- normalizeBits_source_bound (RINormBound): exact represented normalization, derived1024*(W+4)*(N+1)*N work and retained(W+4)*N cells.
- RILifetime: exact initializer work decomposition and explicit lower bounds showing input/temporary/discarded-child close charges are included.

The source scalar cap is not used as a runtime encoder. Every producer consumes supplied Bool arrays. All new producers' nonproof closure, including the prior own primitive definitions, was checked to contain no encode/decode/view or Classical.choose. Mathematical source specifications and controls use decoding/views. The work fields are mathematical source cost metadata; compiled machine evaluation of that metadata is not proved.

Input conversion into the owned representation is a full copyInput/copyForest/copyBits execution. initializeBits closes those owned input copies after the fresh result is constructed. initialCore pays first leaves/Nodup/close on both branches; its accepted branch pays second leaves, owned clipping, build and close. Budget increment/subtract explicitly close intermediate counters, aligned operands and raw result arrays. build copies paths, labels and color heads and closes temporary extended paths. normalizeBits copies leaves/paths, copies merged label/color data and closes discarded normalized children. Retained output ownership is passed to the caller; later run-wide lifetime accounting remains open.

Input guards are explicit: W≥1; each original stored label/color-environment word and budget array length≤W; leaf count<2^W for value refinement. Proper/partition/embedding conditions are unnecessary for the arbitrary initializer value theorem, since it really tests duplicate labels and supplies literal blockColor for any forest. Full final recovery still requires the frozen final source premises. Native Nat input serialization, heap pointer/allocator semantics and GC are not supplied.

Exact import order is new receipt:previous scalar components:actual recovery source:optimizer fees:own early:budget:checker. Six prior source-derived binary primitive modules are reused from their frozen own pool. Foreign binary/functional object pools were not merged. Prior16 object differences and all prior modes/inodes/failures are preserved. The audit uses prior stored producer records only for body-reference closure; this imports no foreign objects.

The next open producer is choose; later erase/attempt/step/run/receipts remain open. No whole recovery bit coefficient, pure-polynomial recovery, native/compiler/IR, independent or full2.33/base/novelty acceptance follows from this package.
