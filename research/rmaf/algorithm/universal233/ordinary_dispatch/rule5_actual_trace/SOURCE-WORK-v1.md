# Source and audit qualifications v1

This release closes the actual selected Rule5 source-level value, callback
frontier, complete-debit mass and label-count/potential bindings. The frozen
frontier keeps every raw overlap occurrence and failed scheduler call, including
the source program's real stopping behavior. The new outer evaluator executes
literal job/request lists and has proved value equality with the original
dispatch/runSelected and parent rule5Answer. No source geometry, desired mass,
ordinary correctness, minimum oracle or global IH is an input to the mass,
label or value theorems.

The source-level frontier is a companion model of actual production guards;
its computation is not a proved compiled-machine execution logger. The
conditional ordinary charge sum covers every emitted ordinary callback once,
including failures and duplicates. It omits no call charge within that sum,
but is not a total caller-work theorem. Selectors, all builder/guard work,
pretests even when they make no ordinary call, refused candidates, local
forest enumeration/materialization, returned payload/reconstruction, original
and fresh numeric labels, addresses, integer/bit operations and budget iteration
remain separate obligations. No free payload/color/max-label operation or
compiled-runtime correspondence is claimed.

Actual callback trees have no greater label count than the old target,
including direct marked common jobs. This does not say their labels are all
original numeric values: marked restriction replaces an actual representative
with a fresh marker. The numeric freshmax and bit envelope remain open.

The canonical replay freshly built8 modules against428 immutable hard-linked
source/olean pairs and extracted303 new stored producer occurrences. Each
producer's actual source origin, imported binary path, declaration kind, type,
full references and transitive axiom closure were checked. All non-theorem
bodies, including nonproof opaque bodies, are retained in compressed producer
logs. Theorem proof text alone is omitted; actual full proof references and
their axiom walks are retained. The only axioms are Classical.choice,
Quot.sound and propext. This is author evidence awaiting review.

Fresh source controls passed clean shared names in both import orders, rejected
hostile names both ways, private/unused axioms and hidden opaque AX dependence,
and checked opaque body retention. Missing/duplicate rows, foreign paths,
source/olean mismatches and adapted-byte corruption rejected. A fresh simple
true/false twin passed/rejected before real producer audits.

Thirteen runtime controls passed on nine actual source fixtures: all seven
selected cases plus actual [2,1,4] and [2,1,2,2] second-case variants. They check
the actual value, literal kind, zero budgets, full payments, gamma mass, proper
sizes/strict budgets, failing direct jobs, duplicate preservation and new
admitted guards. The [2,1,3] original fixture's initial expected [2,1,2,2]
control was false; that entire failed output/source is retained and was not
accepted. Four deliberately false claims rejected with mathematical diagnostics:
common-as-forest, missing failed occurrence, refunded budget, fabricated costs.
All source elaboration failures are retained as separate receipts.
