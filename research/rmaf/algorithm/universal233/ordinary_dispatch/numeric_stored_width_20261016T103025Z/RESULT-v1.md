# Finite-bit fresh markers and storage

The new finite-bit routines compute the actual commonFresh marker and the checked common builder's rho and gamma. They scan represented labels, compare finite arrays, copy every chosen maximum, execute carry addition and copy the returned markers. Their runtime bodies use no mathematical decode, encode, tree-value or source-marker conversion. A source-site theorem equates both decoded marker values to an actual checked Setup's fields.

Starting from stored label width B, freshOne uses at most B+1 bits. freshPair uses at most B+1 for rho and B+2 for gamma. B measures the actual supplied arrays and is independent of the earlier semantic input-label width L. Explicit polynomial fees freshOneFee and freshPairFee pay leaf collection, append, maximum scans, carry operations and copying. Empty and padded inputs are included.

The represented contraction routine checks both cherry orientations with copied finite-bit equality and charges retained-label copies, marker copies and rebuilt nodes. The marked-tree routine charges restriction, finite-bit swapping and reconstructed trees. commonPayloadBits constructs all eight restricted/marked trees. Its source-site theorem matches all eight results and both markers to an actual checked Setup, given explicit equations for the represented source representatives. commonPayloadFee pays the marker construction and every payload constructor. Source guard/classifier and full Setup assembly remain separately owned.

The transport proofs cover the completed restriction, subtree, source-forest and replacement producers. OrientedPath also covers the new contraction and common-payload constructors in either orientation, with at most two extra stored bits per edge. At represented depth d the bound is B+2d. If a complete producer embeds the same depth in the earlier exact semantic trace, d<=Q+N gives state width B+2(Q+N), local marker width B+2(Q+N)+2 and tree-node cap2N. The complete producer embedding is still an explicit obligation; the theorem does not assume a desired global storage record.

Stored budget width has its own initial parameter Bq. The completed disjoint allocator gives the local bound current-width+4N+3 when the source count is at most2N. The new BudgetPath theorem composes the available payment and allocation operations to Bq+(4N+3)D for D operations. A complete producer must prove an original-input bound on D. Budget-operation count has not been identified with ordinary recursion depth.
