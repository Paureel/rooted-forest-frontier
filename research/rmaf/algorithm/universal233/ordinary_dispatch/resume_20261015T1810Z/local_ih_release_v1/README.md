# Budget-local forest exactness — author release

The unchanged executable `GenericForest.solve actual` is exact at forest budget q when the actual ordinary callback is correct at every b≤q. This author release contains a source replay and producer audit. Independent mathematical and interface review remains pending. The complete ordinary algorithm, termination argument, source/bit/payload recurrence, smaller base, and novelty remain open.

`LocalCongruence.solve_congr_budget` proves equality of actual forest execution under equality of callbacks at all budgets b≤q. Its hypotheses impose no callback correctness or state properness. The proof follows actual paid `run`, `schedule`, the allocation bound, disjoint dispatch and decreasing overlap recursion.

`LocalExact.exact_at_budget_bound` combines that executable equality with the separately frozen mathematical minimum completion. The noncomputable completion occurs in erased proofs. The executable solver receives the original callback. `exact_at_current_budget` gives the direct current-budget interface for the ordinary caller.

New records omit theorem proof text while traversing actual full proof bodies for references. Nonproof definition and opaque-data bodies are recorded in full; the full proof binaries are pinned. These checks do not certify compiled-machine execution or compiler-generated partial runtime bodies.
