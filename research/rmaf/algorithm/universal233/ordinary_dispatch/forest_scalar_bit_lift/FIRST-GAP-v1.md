# First remaining main consuming call

The finite binary reference algorithms, counter widths and assembled checker
inequality are proved under the explicit input/payload label-bit cap. Every
required scalar cost bound is derived from a printed algorithm body.

The next actual implementation binding is the representation boundary:
`referenceEq W x y` describes `copiedEqual (encode W x) (encode W y)`.
The declared work charges the supplied bit-array copy/comparison provider,
not native Nat encode's division/modulo or native Nat.beq. The checked reference
cost therefore cannot be substituted for compiled FastOrdinary runtime until a
persistent binary representation/provider (or measured/proved native scalar
backend) is bound to the actual program, including conversion/copy lifetime.
No native encoder cost or backend assumption is silently introduced here.

The parent also retains current-budget/whole-bill application, Rule5 fresh
max/common-contraction input label cap, all remaining primitive bill scopes and
main/independent acceptance. Exact source constraints remain q=k_opt-1,
conditional c=2.33, no implicit rho. This release changes no production runtime.
