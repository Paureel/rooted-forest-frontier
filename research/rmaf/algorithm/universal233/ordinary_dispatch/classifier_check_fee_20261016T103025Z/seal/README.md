# Classifier CheckRequest fee

This problem-specific Lean adapter supplies the source inspection fee for the frozen classifier's embedding and restriction checks. Use `ClassifierFeeBinding` for the exact final classifier and paid builder theorems. Import `ClassifierFeePolynomial` when rewriting the uniform cap to its explicit polynomial. The compatible paths are listed in `PUBLIC-INTERFACE-v1.json`.

`requestMeter` returns the exact source Bool, its inspection bill, and the unchanged single request occurrence. `false` is a normal refusal. `checkCap N` bounds every request in the frozen bounded domain, regardless of truth. The model includes two inspections for request dispatch and primitive invocation and reuses the existing checker units. Binary/native execution and instrumentation runtime are separate obligations.
