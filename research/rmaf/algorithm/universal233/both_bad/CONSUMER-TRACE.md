# Original agreement to actual calls

1. Start with an original agreement F refining source P=[A,B,C]. Any block
crossing the selected target edge occupies its original child endpoint. Original
agreement ownership permits crossing blocks from at most one parent. All blocks
of the other parent are monochromatic for the literal side color.
2. Actual source coverage produces an output in one of the two literal core
lists with F refining Q. Source validity and original nonredundant output cuts
come from the completed source generator, not from a subset of F's cut addresses.
3. Successful probes reuse the same entire output list. For a cheap output,
the selected original edge proves its target embeddings disjoint. A bad sector
supplies two actual bad parents, so even a sole hard ordinary query pays another
parent. Good sectors discover an actual minimum-one A completion.
4. In every opposite output, whole A/C preservation yields an exact permutation
of the current source components into A / whole Bforest / C. Every feasible F
pays at least one additional A cut. The actual Bforest query at q-d-1 is therefore
complete; the A completion and C combine with its result. No within-B target
clearance or whole-B tree replacement is assumed.
5. The dispatcher executes each actual callback once. It checks returned
candidates with the original agreement predicate/global q and chooses minimum
length. PlanCover proves a candidate no larger than every feasible input F;
execute_complete transfers it through this literal minimum selection.
6. Trace mass uses the exact recorded callback budgets. It includes all raw
output occurrences and failed paid calls. The cheap bad-sector branch gains
c^(-1) from the actual paid scheduler. The good-sector branch gains c^(-1)
on each opposite whole-Bforest call. Both-high mass is4*c^(-4); each mixed case
is at most c^(-3)+c^(-4), hence4*c^(-4) when c<=3.
7. Source-prefix bills retain both probes, optional full generators, refusals
and overbudget attempted prefixes. Local pretests, restrictions, output/payload
copies and actual left append cells are listed in the source-operation model.
That model's inspection correspondence remains separate from Lean's value,
trace, billing-arithmetic and graph theorems.
