# Binary consumer interface

| Object | Exported statement | Scope |
|---|---|---|
| `solvePair` | Dispatcher | Actual guarded q3 probes, cached source lists, concrete recursive callbacks, original check and minimum selection |
| `ExactAt` / `ExactSolverHyp` | ForestContract / PlannerGeometry | Explicit future recursive exactness IH, never an implementation or runtime claim |
| Original F coverage | `solvePair_conditional_cover` | Every original agreement F refining checked P and within q; returned H is an original agreement, within q and no larger |
| Original soundness | `execute_sound` | Any oracle; executable original predicate and budget check |
| Callback bound | `solvePair_actual_mass` | Any oracle; every rational2<=c<=3; actual trace mass<=4*c^(-4) |
| Decrease | `solvePair_calls_drop` | Every literal callback has child budget+3<=q |
| Prefix bill | `corePrefixBill_bound` | Actual planner core-request schedule; completed full-prefix model envelope |
| Output occurrences | `plan_length_bound` | Actual retained lists, with duplicate occurrences counted |
| Recursive bill | `profilePair_recursive` | Exact sum of supplied charges evaluated on the actual target/source-list/budget calls |

Full/retained children are finite ForestState inputs; target overlap within
their source lists is allowed. Ordinary children are literal restricted pairs
and use the completed disjoint MAF caller's explicit target-Q disjointness.
The known local source cut is not unioned with opposite original cuts. A final
original-cut recovery is a later once-after-selection consumer.

All source hypotheses appear directly in the theorem signatures. Original
partition refinement, paid-one lower bounds, actual rank4, cached-list equality,
source validity and target clearing are derived from completed proofs. No
structure field assumes a desired graph cover, cut nonredundancy or mass bound.

The only import edit in the completed stack is the already-declared filename
adapter MafCaller: Reconstruction -> GroupReconstruction. Proof bodies are
unchanged. DISPATCH-SOURCE-PINS-v1 records the completed original and copied
hashes. Final replay rebuilds every module from source in one isolated directory.
