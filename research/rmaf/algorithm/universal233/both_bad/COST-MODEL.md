# Source-operation scope

The mathematical bound concerns actual recursive calls. A weight is
c^(-(q-childBudget)); CallDecrease proves childBudget<=q-3. It is not a count of
compiled instructions or a complete running-time theorem.

Core prefix work uses the completed CoreWork meter and its reviewed conservative
source-operation bridge. Its known helper/fine-operation mismatch79 versus86
remains excluded from any identity claim. coreRequests follows the actual
planner order: both budget3 probes; then both full generators if both probes
fail, or the unsuccessful opposite full generator when only one succeeds.
At most4 requests are made, each at budget<=q. corePrefixBill_bound imports the
full prefix/refusal/prune envelope. The finite parent/side color scan is paid
by colorPrefixBill for every original leaf/request. Original descendant
calculation, sector inspection and knownOne setup have explicit caller terms.

| Actual work | Charge retained by profilePair/profileExecute |
|---|---|
| Descendants, parent labels, all probes and knownOne/depth01 setup | callerUnit times actual parent/descendant/entry counts; corePrefixBill plus colorPrefixBill |
| Every guarded output occurrence | actual output block/label/address cells and entry visit |
| Ordinary prepare/pretests/literal restrictions/paid scheduler/final SUM | callerUnit per entry; recursive callback charge is separate |
| Full sourceForest / retained whole-Bforest materialization | callerUnit and actual output cells |
| Retained known A / child B / completed C concatenation | callerUnit and returned answer cells |
| Original agreement predicate and minimum-length selection | callerUnit and actual returned answer cells |
| Outer immutable-list append | actual left r.calls.length; no tail-list copy charge substitution |
| Recursive work | exact sum of charge(actualTarget,actualSourceList,actualBudget) over literal calls |

callerUnit is a conservative polynomial in original tree nodes and q. Its
helper-to-primitive source correspondence requires review. No kernel theorem
identifies that arbitrary polynomial with every fine operation. Returned
payloads remain visible rather than being discarded after value projection;
their polynomial bound uses correctness/proper-label contracts of the future
recursive solver. Numeric-label, budget and counter bit-operation costs are
additional polynomial encoding factors. No arbitrary color-oracle cost is
assumed constant.
