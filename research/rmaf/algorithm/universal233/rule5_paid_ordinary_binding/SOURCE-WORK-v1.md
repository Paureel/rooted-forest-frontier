# Paid ordinary source work v1

`currentQuery` executes the frozen full-state pretest first. Its found
forest is checked against the actual residual r. A rejection at r≤1 returns
answered none. A larger rejected query calls the unchanged executable
`GenericForest.solve actual T ss r` with the same actual callback. A
malformed pretest result remains an explicit CurrentResult.malformed.
`currentAnswer` forgets that tag only for flattening; every actual emitted
request is proved proper, hence cannot take the malformed path.

`answers` keeps every affordable request occurrence and its original full
cut-list residual; it does not deduplicate or refund any payment.
`bestFor` checks the original agreement predicate and q=k-1 budget on each
returned forest before choosing minimum length. `solveSelected` retains a
separate builderRefused outcome; actual selected-second nonrefusal is
proved from the printed original guards.

The pretest's exact candidate bound and the selector's ≤16 source rows per
original source vertex are inherited frozen inputs. Original labels,
source-tree payloads, vertex-address lists and full cut lists retain their
actual representation costs. Arbitrary Nat labels require their true bit
cost; no constant-cost arbitrary integer, compact forest encoding or
compiled-machine timing claim is assumed. This continuation adds finite
pretest/match, list filtering/flattening, original checks and best-selection
work. It does not supply a formal instruction bill for the inherited
GenericForest program or a whole-algorithm recurrence.

The only correctness hypotheses are LocalOrdinaryIH at each actual query
residual, supplied by ∀r<parentq LocalOrdinaryIH r actual. Positive full
original cut-list payment proves that residual is strictly smaller. The
imported LocalExact theorem uses mathematical completion only in erased
proof support. No new executable definition invokes minimumCallback,
ghost, Classical.choose or an optimum oracle. The actual callback is passed
unchanged to every executable forest fallback.

All179 dependency source/olean pairs are hard links to immutable releases,
pinned separately by source and proof-binary SHA256. They are never rebuilt
or mutated. Only this continuation's new modules may compile or produce
new declaration audits. Existing failure records remain retained.
