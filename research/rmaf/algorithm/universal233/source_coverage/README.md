# Source partition refinement and raw output mass

This package extends immutable universal233 core, geometry, and integration sources. It proves finite-budget original-label partition refinement through the actual `generate`, an all-output recorded-color cost lower bound, and raw rational output-list mass. The complete faster rooted-MAF algorithm remains OPEN; see `RESULT.md` and `FIRST-GAP.md`.

From the BootLoops workspace root, run:

    ./bootloops-python research/rmaf/algorithm/universal233/source_coverage/replay.py

Every run creates a fresh local receipt and preserves earlier ones. The script compiles exact source copies, inventories declaration origins including private/generated names, checks the permitted axiom set, runs true/false controls, catches omitted audit records and a hidden custom axiom, and checks frozen hashes before and after. `LATEST-REPLAY.txt` locates the last receipt.

| Module | Content |
|---|---|
| FullTransport | Actual normalization occurrence surjectivity, payload containment and source-owner transport |
| Coverage | Finite owner budget and original group refinement through exact step and run |
| Entrypoint | Original Boolean checks and original partition through exact generate/min cap |
| OutputBudget | Every emission fits its requested cut budget; coverage consumes this bound |
| ColorBudget | All-emission recorded cost at least distinct colors minus one |
| ColorSteps | Actual chooser no-unique-color fact and color preservation in both branches |
| RawMass | Denominator-cleared raw emitted-list mass for every integer base at least two |
| RationalMass | Universal rational mass and explicit negative-power output-list sum |
| Controls | Required positive controls, theorem consumers and literal list multiplicity |

The code is problem-specific. Original residual cut components and polynomial work per prefix are separate proofs. Author replay is separate from fresh nonauthor review.
