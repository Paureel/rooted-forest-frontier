# Remaining actual-generator consumers

The finite-budget original-partition refinement and raw rational output-mass obligations have author Lean proofs in this package. The full faster rooted-MAF algorithm remains OPEN.

The first separate graph consumer occurs when the exact `CoreProgram.attempt` calls

    continuation next (g :: detached) (g.origin :: cuts).

A reachable-state proof must identify the residual components of the ORIGINAL source after deleting every recorded edge `(p.dropLast,p)`. Immediately before a successful attempt, every recorded edge and live origin must belong to the original graph. Adding the selected `g.origin` must split the one live residual component into two leaf-bearing components whose label sets are precisely `g.labels` and the surviving live payload, leaving all earlier detached components unchanged. At finish, these exact residual leaf sets must equal the literal `Output.partition`, without extra leafless components.

That original-component realization is a separate obligation. This package proves transport and refinement on the actual suppressed grouped graph; it does not replace original connectivity by a displayed edge or assume component realization in a structure field.

After original-component realization, the remaining consumers include a polynomial bound on the actual tree/list/address work per prefix and complete integration with the ordinary rooted-MAF solver and its claimed global exponent. The existing prefix-count theorem is exponential in the cut budget and retains that scope. All required independent nonauthor review remains separate.
