# Actual whole-source construction work

This package consumes the frozen core-work meter on the frozen whole-source
clique, four-chain and diagonal generator lists. It proves exact output
projection, concrete original-label color costs, exact accepted/refused color
call counts, polynomial finite-geometry construction, and outer list-copy
charges. The full faster rooted-MAF algorithm and all three main milestones
remain OPEN. Fresh nonauthor review is pending.

Run from the workspace root:

    ./bootloops-python research/rmaf/algorithm/universal233/whole_source_work/replay.py

The wrapper copies its pinned sources into a new
`results/algorithm-universal233-whole-work-*` directory and builds only those
copies. It verifies both frozen input manifests, recompiles every proof
module, inventories every declaration by originating module (including
private/generated declarations), and checks the complete axiom dependencies.
Known true/false, source-pin, missing-audit-record and private-custom-axiom
controls accompany the result. A successful receipt means an author source
cost argument with kernel-checked projections and inequalities. It does not
replace a fresh nonauthor source-operation review.

`COST-MODEL.md` states units and the source correspondence. `RESULT.md` gives
scope, formulas and remaining consumers. Failed development compilations are
retained in `dev/`; the replay's logs and certificate are its evidence.

This is a one-shot problem-specific instrument. The BootLoops toolkit index
and immutable core/mass replay interfaces were consulted; none implements
these original-label color costs and this actual caller composition. This
package extends those interfaces without changing their source or results.
The full toolkit suite and finite census are deliberately outside this local
proof replay.
