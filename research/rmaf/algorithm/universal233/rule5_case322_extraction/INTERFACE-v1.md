| Module / theorem | Exact result |
|---|---|

| callbacks_swap / exactChild_swap | Raw callback list and conditional exact-child contract transport unchanged |

| rawPlan_original_cover | Universal original-AF no-larger cover for the computed original-path branch list |

| target_currentGuard_of_nonredundant | Reduces the target current guard to actual distinct nonroot valid arcs and exact paid+1 component count |
| PlanCosts / rawPlan_cost_classes | Raw costs are [2,1,2,2] or [2,1,d] with d≥2; d can be four or larger |

| PathSpecification / bside_literal_spec, cside_literal_spec | Exact original path-side pendant predicates |
| bside_without_a_literal_spec | The excluded label-containing pendant is exactly the original terminal a arc under the actual cherry |

The source primitive is the actual lookup `bottom sa sc sb a b c X`, with
three independently quantified Boolean child orientations. The target core
is an actual original descendant subtree with original complement labels.
These are local graph hypotheses, not saving/cover fields. Global admission
classification remains outside this package.

`rawPlan` retains all selected original addresses and all branch occurrences.
The b-branch address must be the actual source b terminal address; the pending
universal guard target fixes it to `bArc w sb`. A raw AF cover alone does not
prove that its branch arc metadata is payable. FIRST-GAP-v1.md defines the
missing consuming proof.
