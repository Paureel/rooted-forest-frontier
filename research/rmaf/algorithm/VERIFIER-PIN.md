# Nonauthor integration verification pin v1

Written before a design-route delivery. The verifier authors no candidate
algorithm or constituent proof. No route may consult verifier-generated
reserved values while designing a candidate. X0 values used in design are
development data; reproduction is required, but is not held-out validation.

## Frozen scope and independent implementation

Read the original spec, this pin, source definitions and literal frozen
controls before reading candidate code. Immediately write the verifier
workfile, then build a fresh explicit graph/edge-cut enumerator with retained
positive/negative controls. Reuse no candidate, X0, or earlier oracle
implementation. Prefer graph connected components after source edge cuts and
an independently expressed rooted topology predicate. Shared mathematical
definition/source and Python runtime must be recorded as shared layers.

## Controls

- Literal forced-cherry, endpoint, incomplete-cover and rational plants from
  X0's frozen files: reproduce every preregistered value. Distinguish original
  24 controls from five later supplementary source-predicate controls.
- Hand-constructed empty and singleton cases: zero and one components.
- Distinct rooted triplets ((0,1),2) versus ((0,2),1): optimum two components.
- Crossed quartets ((0,1),(2,3)) versus ((0,2),(1,3)): optimum three components;
  pair partition {0,2}|{1,3} has intersecting target spans and is rejected.
- Duplicate/missing labels, wrong topology, shared root, unary suppression and
  marked/root handling where consumed by the candidate; clean twins pass.
- On a COPY of a candidate/harness remove a required branch while preserving
  a nonempty cover, perturb a cut charge and a recurrence term. Demand explicit
  exact failures; no candidate or original frozen file is modified.

## Reserved finite sample

After controls but before inspecting candidate implementation, freeze sixteen
ordinary eight-label tree pairs generated by a fresh random-tree generator
using seed 40871. Their exact values are not computed or shown to designers.
They are finite supplementary validation only. Record actual call-site counts;
zero macro-eligible children cannot validate the macro. If a route requires a
different in-regime family, pin the new family before execution and call it
supplementary/post-hoc rather than retroactively held-out.

## Verification order and ruling

Freeze the delivered source hashes. Reconstruct total state/rule priority,
applicability, terminals, fallback and original-forest reconstruction from the
written candidate; run its full entry point on controls and reserved sample.
For every cover emit all charged children and independently compare optimum
survival, feasibility, reconstruction and emitted rational mass. Time a small
pilot before any extended census. No optimum oracle is a candidate step.

Review every universal proof, turn every implicit import into an exact
consumer-hypothesis row, and replay each accepted Lean module in an isolated
output directory. Require no sorry/admit/custom unproved axioms/native_decide,
complete `#print axioms` reports, and controlled false-proof rejection. Any
conditional theorem keeps its hypotheses open unless supplied at the actual
algorithm call site. Trace generation/precut/local-query/reconstruction costs
and q=k−1 conversion in the full recurrence. If a candidate fails, retain the
smallest executed witness and mechanism. A finite no-fire cannot establish a
universal proof or a smaller base. Verdict labels: CONFIRMED-SCOPED,
REFUTED-AT-WITNESS, or OPEN-AT-NAMED-OBLIGATION.
