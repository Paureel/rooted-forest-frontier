# CB4 bounded review instruments

These one-shot scripts verify the completed CB4 partial guarded frontier on
its nine frozen inputs and two requested budgets. Use them to replay this
specific certificate/coverage review; they are not a general search engine,
new census or universal alpha proof. The inherited independent instrument is
adversary/independent_cb1.py, whose source hash is recorded in JOURNAL.md.

`review_cb4.py` without arguments executes the frozen clean/corrupt guard and
coverage controls. `--covers` verifies all 18 generated covers against the
original graphs and independent partitions/local-distance scores, with
production scoring helpers blocked during generation. `trace_dominance.py`
repeats only the six already-scored runs containing a compiled branch and
checks substitution against actual original minimum cutsets.
`check_quantifier.py` replays the two actual states that refute an overly
strong all-reachable-states reading of the coverage sentence.

Passing output establishes the finite claims named in each receipt. It does
not prove universal C1, the terminal-completion interfaces, alpha generation
bounds, novelty, or a Lean theorem. Before trusting the finite result, require
the frozen controls with rejected cost/support/source/half-budget corruptions,
source-id graph isomorphism checks, direct local original-cut realization,
actual local scoring, and existential original-optimum survivors per cover.
REVIEW.md gives the conditional proof review and the precise state quantifier.

All evidence uses the new results/algorithm-balanced-cover-continue-review-cb4-
prefix inside research/rmaf/. Preserve its frozen receipts during replay;
use versioned output paths rather than replacing retained evidence. The
parent's source, previous pins, previous receipts and own CB1 proof remain
unchanged by this review.
