# CB2/CB3 nonauthor review instruments

The scripts reconstruct the completed six-leaf obstruction from the actual
ordinary trees and review its structural compilation, costs, implication and
scientific scope. Use them for this fixed source-model review; they are not
general solver tools or a new census. They reuse only the frozen independent
CB1 tree/conflict instrument for mathematical primitives.

`compare_cb23.py` is the frozen preimplementation transition design. Running
it without arguments executes its six-corruption control gate. Its optional
source leg preserves the initial strict comparison that fails because it
uses a stronger non-singleton fixed point than the receipt's stop rule.
`reconstruct_modes.py` runs both interpretations, compares their primary
profiles and replays the implementation after declared code contact.
`check_source_causes.py` independently rebuilds all literal conflict causes
and demonstrates the RESULT empty-wrapper issue.

A passing output means the listed finite claims reproduce, with exact
integer/Fraction comparisons and retained negative controls. It does not
prove C1, universal solver correctness, a global runtime, stronger reduced
eligibility, novelty or a Lean theorem. Before believing the source claim,
require the preimplementation control receipt, exact original-tree/cause
reconstruction, all-row replay, Boolean implication checks, and the lineage
notes. REVIEW.md is the human-readable verdict; referee_sim_RESULT.md and
PROSE-LINT-RESULT.md contain separate text audits. No parent files were edited.

All scripts are one-shot instruments. Their outputs have the new
`research/rmaf/results/algorithm-balanced-cover-continue-review-cb23-` prefix.
Preserve the frozen receipts when replaying; direct a versioned replay to new
output paths rather than replacing the retained evidence.
