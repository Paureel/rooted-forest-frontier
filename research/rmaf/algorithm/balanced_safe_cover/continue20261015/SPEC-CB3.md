## Actual algorithmic choice

minimal conflict row, using exactly CB2 structural closure and residual-CNF

Select the row with smallest mass, ties by row mask. All rows, child closures,
CNF tests and exact rational arithmetic are paid polynomial work per search
state; no oracle is used. Residual states are cached by original edge masks
and remaining budget, root factors optimized separately as before. Successful
full certificates are checked on the actual original trees and have tau0.
