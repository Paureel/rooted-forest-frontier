# Global conflict continuation instruments

These are one-shot problem-specific research instruments. The general
BootLoops index, the rMAF algorithm guide and the existing conflict/quotient
instruments were consulted before implementation. Frozen earlier sources,
controls and receipts are unchanged. RESULT.md records the exact limitations.

| Instrument | When to use | Output means | Required check |
|---|---|---|---|
| conflict_solver.py | Literal CB1 factorized original-conflict search | Budget failure or one complete minimum certificate, conditional on C1; paid search trace | Pinned CB1 controls and independent source/model review |
| conflict_dag_solver.py | CB2 forced closure, residual implication, cost domination and exact caching | Same decision/witness object with structural child traces; no global base guarantee | CB2 clean/corrupt twins, source-bound Lean generic implication, new nonauthor review |
| conflict_row_selector.py | CB3 paid choice over every minimal row | Exact rational row masses and one selected row; all-row recurrence can fail | Replay every compiled row and original-edge certificate; no finite-to-universal inference |
| guarded_frontier.py | Generate actual partial guarded original cut certificates | Explicit original local witnesses and terminal geometry; global alpha bound open | CB4 source/cost/support corruption controls and new independent coverage review |
| check_cb1.py / check_cb2.py / check_cb3.py / check_cb4.py | Replay frozen controls | Exact fixture, corruption and optimizer-ban counts; shared production scoring | Expected denominators and deliberately rejected twins |
| branch_profile.py / freeze_obstruction.py | Rebuild the explicit recurrence obstruction | Literal source edges, residual rows, cuts and exact masses; no asymptotic lower bound by finite count | Compilation replay, false cost/mass controls and fresh source reconstruction |
| audit_cb2.py / audit_obstruction.py | Replay new scoped Lean statements | Source-bound compiler/axiom evidence plus rejected false propositions | Exact source hashes, expected report counts, no prohibited proof tokens |

Use the workspace runtimes, for example:

```
./bootloops-python research/rmaf/algorithm/balanced_safe_cover/continue20261015/check_cb3.py --ordinary-limit 9 --output algorithm-balanced-cover-continue-cb3-replay.json
./bootloops-python research/rmaf/algorithm/balanced_safe_cover/continue20261015/audit_obstruction.py
```

The scripts import only local code. No source, data or evidence is uploaded.
The scientific acceptance standard is separate from a successful exit status.

CB4 inherits CB3's exact row-ranking score as an implementation choice. Its
partial outputs still need paid terminal completion, so the full-certificate
alpha7/3 theta0 alternative does not apply to CB4. The original guarded-cover
alpha5/4 or prelicensed3/2, theta1/2 bound remains the missing theorem.
