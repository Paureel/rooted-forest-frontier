# Qualified source work

The source materializer and grouping definitions support the claimed conservative O(n^3) count under unit-cost label equality, when the materialized source list is evaluated once and the three owned filters are evaluated on it. This is an inspection of source operations. No compiled instruction correspondence or recursive solver runtime theorem has been established.

Let S be proper binary with n distinct labels and N=2n-1 nodes. For checked Q, let k=|Q|. Its nonempty disjoint blocks give k≤n and sum |U|=n. A restriction to U traverses at most N original nodes and performs linear membership in U at selected leaves. A coarse all-block count is O(N(sum|U|+k))=O(n^2). Unary suppression does not introduce an oracle. Every materialized tree has at most N nodes, so O(kN)=O(n^2) retained node data is conservative.

owned ss U filters every actual current source component using contained(leaves s,U). Naive leaves construction uses append and is at most O(N^2) per source tree; containment is at most O(n^2). Three filters over at most k trees therefore cost O(kn^2)=O(n^3) in this deliberately coarse model. Direct A/C restrictions fit inside that count. The value-level checker/permutation/grouping proofs do not themselves supply an executable scheduler that binds and shares this list; repeated invocations must each be charged. Allocation, sharing, garbage collection and stack behavior are outside this count.

The isolated scientific definition closures have 13 names for sourceForest, 13 for owned and 45 for ForestState.agrees. None reaches assignments, blocks, solve, generate or pretest01. This establishes the scoped source dependency claim; it does not bound the upstream source generator, full state checker, proof elaboration or a future recursive callback. The full state checker itself is outside the O(n^3) materialization/selection claim.

Nat comparisons cease to be unit cost when labels have bit length ℓ; their bit work must be charged, conservatively multiplying relevant comparison costs by a bound for ℓ. Label storage also requires its bits. The whole-B child query has an unknown, explicit recursive bill. A minimum or positive optimum does not reduce a query's runtime. Transporting the exact ResidualSolverContract does not pay that bill or implement the callback. No whole-algorithm recurrence or base bound follows from this source-work account.
