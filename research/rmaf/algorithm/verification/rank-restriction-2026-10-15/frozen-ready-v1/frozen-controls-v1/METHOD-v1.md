# Prerelease method

The rank feasibility instrument enumerates only the fixed trees with at most
four original leaves, retaining all Bell partitions (at most fifteen). It
checks actual original partitions, embedding disjointness, and monochromatic
blocks. The independent graph machinery is reused from this same reviewer's
sealed pre-candidate G/E controls; this is no new replication lineage.

The new source-program interpreter follows only original CoreProgram's
constructors, homogeneous contraction, unique-color priority, mixed-cherry
priority, erase and cut-budget recursion. The separate BFS graph checker
removes each reported original edge and compares actual leaf components with
the output partition. It checks every raw output occurrence, preserves list
multiplicity, and uses exact Fraction masses. Original output cost is the
literal source-cut list length; no optimum is used as an implementation step.

The restriction checker prunes the original trees while retaining a map from
every displayed vertex to its original address. It expands each displayed
edge through the original BFS path and compares the result with the original
minimal embedding of each hand-fixed local subset. Mere displayed-vertex
images deliberately fail on unary paths. The checker constructs local F_U
by filtering F for containment in U, verifies actual local agreement, and
checks nonempty families before computing integer costs. Reverse tests keep
source and target Q-disjointness as separate original-graph predicates.

Literal controls distinguish local cost sum from total cut cost by the
|Q|-1 offset. Missing local families can satisfy a saturating Nat cost identity
and still fail the actual local input and label checks. Dropping either source
or target Q-disjointness admits the pinned false reconstruction example. The
five- and six-leaf clearing examples are fixed graph checks only; neither is
enumerated. Every Q block avoids one or two requested vertices, while two Q
embeddings still intersect below them.

The instrument and exact expectations are frozen before execution. A one-case
pilot runs the same path first. Only then does the fixed battery run, with
five-second per-case and twenty-second total limits. A failed literal pin,
unsupported condition, or timeout remains open and is retained. Each literal
equality comparison has a clean twin and a deliberately mismatched expectation;
additional raw-list and local-family corruptions target the actual semantics.

No candidate rank/restriction source or current consumer implementation is
inspected, and no Lean candidate compilation occurs during preparation. Lean
source-only isolation, complete private/generated originating declarations,
custom/private/imported/unused axiom plants, and every actual consuming
hypothesis are preregistered for the later exact-manifest release. A positive
optimum does not establish a cheaper query, and requested clearing alone does
not imply full Q target-disjointness. All main milestones remain open.
