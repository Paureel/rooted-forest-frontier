## Exact statement

The input is T : Option RMAF.Tree and ss : List RMAF.Tree. Leaves carry
arbitrary Nat labels. The original full-state Boolean agreement predicate
checks target labels, each source component's labels/topology and BOTH
original target/source embedding hulls. Unary restriction suppression does

The actual current additional cost is |F|-|ss|, using Nat subtraction;
ordinary |F|-1 applies only to a one-component source. Initial q=k-1 and
no implicit rho remain the main problem conventions.

The supplied definition-only program enumerates the unchanged source label
partition and every original nonroot edge cut in exactly one current source
component, leaving all other current source blocks present. It checks the
entire candidate with the original full-state predicate and chooses the
minimum additional cost among accepted candidates. Results distinguish
refused (malformed), rejected (proper but no cheap answer), found F.

Review these claims, including all quantifiers:

1. For EVERY actual full-state AF of additional cost <=1, a generated
   candidate has the same cost and agrees with it up to inner-label and
   outer-block permutations. ForestPerm contains permutations/composition
   only, never an agreement/minimum/desired-coverage field.
2. A found answer is an original full-state AF with cost <=1 and is globally
   minimum against EVERY actual full-state AF, not merely the candidate list.
3. Rejected implies proper input and EVERY actual full-state AF costs >=2.
   Refused is equivalent to malformed input. Do not infer infeasibility from
   refusal or conflate Option/empty target with a nonempty tree.
4. The exact candidate count is 1+sum(original current-source edge counts),
   with the qualified upper bound 1+2n. Repeated edge partitions remain
   separate candidates. No optimum callback, ordinary IH, target-Q
   disjointness, normalized cover record or uncharged exponential oracle
   may be assumed.

Internal target overlap between different current source components is in
scope. The pretest must see it. Current-component edges and final ORIGINAL
global source-cut recovery are different interfaces; no free global cut
union or per-node recovery cost is licensed.
