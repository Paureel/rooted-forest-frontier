# Exact import/source qualification

The release path union is not a compatible import pool. RECHECK-PLAN-v7 names each selected source, source pin, canonical root, extra roots and theorem list. Fresh compilation copies the selected source byte-for-byte into its own directory and prints each actual consuming type and axiom list. These are same Lean/compiler/tool lineage checks, not independent origin or functional verification.

Rule4 adds only its own build before its one exact source-integration context. Numeric adds only its13 own frozen objects before that same integration context. Hard2 and binary producer each use their own self-contained canonical context; no v7 unrelated pool is merged. Setup/paid/literal use only the four compatible roots printed by Literal PUBLIC-INTERFACE (the setup case uses the latter three).

Recovery uses its new RS root, the exact old recovery root and previously declared source/optimizer/checker context. The frozen own v6 OWBudgets import-only adapter is reused without rebuilding: line1 imports OWOptimize instead of OWControls; all other source lines/theorem bodies are identical. This is a direct-import adaptation, not a claim that all transitive proof/control namespaces are absent. The original v6 receipt and v6.1 correction remain frozen. No author control source or program is explicitly compiled or invoked. For example BinaryProducerAccounting directly imports prebuilt BinaryProducerControls; NumericLocal imports prebuilt NumericPrecontrols. Other transitive proof namespaces may also load. Initializer execution/closure has not been separately audited.

The runner hashes all available direct .olean members in declared roots, plus the selected source; this is an availability/pin ledger, not observed transitive-import closure. Own controls also load those contexts. Fresh selected source/kernel success verifies elaboration and displayed standard axiom closure; it does not independently audit all imported proof bodies, compiler/backend correctness or heap costs. Author metadata about retained full bodies remains attributed, never promoted by a hash match.
