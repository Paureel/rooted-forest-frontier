# Released review protocol

Readiness was sealed before the root released final G and E. Both original
sources remain immutable. The fresh driver verifies every G delivery hash and
each E snapshot/origin hash, explicitly distinguishing the two generated audit
descriptors from file paths. It copies source only into separate empty G and E
directories, sets LEAN_PATH only to that directory, and compiles each module
with the pinned local launcher. Every log and failed detector attempt remains.

The preregistered own clean, explicit-false, unused/private custom-axiom, and
imported custom-axiom controls execute before candidate compilation. A source
token scan covers all scientific modules. A fresh complete module-origin audit
covers all declarations, including generated/private declarations, and rejects
every axiom declaration, every unsafe declaration, or a transitive axiom outside
propext/Classical.choice/Quot.sound. The Lean origin/collectAxioms API came from
the released audit files; the driver and formatting are freshly written. This
shares the kernel and metadata mechanism, which is stated rather than counted
as independent numerical implementation evidence.

The same-machine source-bound author receipts measured each module in under
six seconds and the full audits in about four seconds. The first own tiny
detector compile measures the current machine before scientific replay. Each
invocation has a 40-second cap; failure or timeout leaves its scope open.
Progress is completed source modules and exact audited declaration records.
Existing oleans, author Python runners, and author numerical checkers are not
used. The original 43 literal controls and finite fixtures are replayed from
the immutable own readiness sources after release.

After separate isolation, a joint copy may use the exact common RMAF, Geometry,
Bridge bodies and the exact Selector and E proof bodies. Separate Controls
modules keep their original names/bodies in their own isolated copies. The
joint semantic adapter must prove original vertex/edge to treeAt existence,
descendant label membership equivalence, sector-filter equality and full
clearance equivalence before applying E. Every original proof-body hash is
preserved. The adapter will not claim reached-state history, residual source
operations, source-cost charging or a complete faster solver.
