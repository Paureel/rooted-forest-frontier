# Fresh exact instrument

`exact_x0.py` is a one-shot public-target test instrument. It enumerates set partitions directly; tests rooted topology by the family of induced descendant clades; constructs original unsuppressed hulls by undirected graph BFS; and checks every pair of original embeddings for vertex-disjointness. No desired common-split property is assumed by the optimum oracle.

Use it for this finite X0, with the public definitions and guards. It is not a fast algorithm, acyclic agreement forest checker, universal proof, or registered oracle. Sibling order affects graph addresses but not rooted topology signatures. Every leaf label is a distinct nonnegative Python integer. Empty sides, marker collisions, absent representatives, and missing actual cut edges fail before identity evaluation.

Outputs are exact costs and complete minimum block families. `bank` writes one JSONL row per representative choice, retaining all original edge alternatives and orientations, plus a summary denominator. A row with `fires` names a candidate failure; it requires guard and literal replay. A clean bounded bank is NO-FIRE finite evidence only. The seconds cap is 50 soft and 59 hard. Control mismatches raise and halt.

Before believing any output: the frozen hand controls, all named corruptions, and label/order variants must execute; exact fields compare with zero tolerance. A separate author/spec-only independent implementation would still be required for mathematical certification. This implementation shares its Graph layer between partition/hull evaluation and cut-witness reconstruction, so those are complementary checks, not independent route certification.
