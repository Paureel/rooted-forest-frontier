# Preregistered literal controls and finite search plan, v1

Frozen before any scientific engine execution, 2026-10-15. Expected integers and minimum families below are hand derived, never generated by the instrument. Any mismatch stops evaluation; correction keeps this original and creates an erratum. A genuine in-regime identity mismatch is a FIRE only after literal guard/embedding/cost replay; no-fire never proves the universal identity.

## Representation and acceptance

Tree `[a,b]` denotes a rooted binary node with unordered children. A bare Nat is a leaf. Original vertices are binary string addresses with root `""`; retain every vertex, including those suppressed from restricted topology. Exact AF = partition, matching induced rooted clades per block, disjoint original undirected BFS leaf hulls in each tree. Cost = number of blocks minus 1. Every valid original common-split edge in each tree is retained, and X-child / Y-child orientations are counted separately. Representatives range over all X×Y. Fresh markers 100 and 101 when labels are 0..4; transformed labels use 1000003 and 1000033. Zero disagreement tolerance.

## Corruptions, clean twins, and required catches

1. Incorrect marked attachment: control C marked-X T falsely `[[0,1],100]` in place of `[0,[1,100]]`; literal marked-tree equality fails before optimization.
2. Collision: rho=0 in A; freshness guard rejects.
3. Absent representative: y-rep=99 in A; representative guard rejects.
4. Missing common edge: balanced A tree with X=02,Y=13; no actual cut edge represents split; guard rejects. Its otherwise pairwise local shapes must not license identity evaluation.
5. Invalid original hull/target embedding: A partition `02|13` has matching 2-leaf restrictions but original hulls intersect at root (and others); AF checker rejects. Its fake target hull with internal vertices removed must fail literal hull equality.
6. Off-by-one cuts/components: A empty-cut leaf-bearing component count1; falsely claiming cost1 fails the exact `components−1` comparator. C two-block witness cost1, false cost2 rejected.
7. Discarded original suppressed/leafless vertex: A block02 hull contains `['','0','00','1','10']`, although its restricted two-leaf topology suppresses original0/1 vertices. Dropping original vertex0 fails hull equality. A cuts root→0 AND root→1 leave the root component leafless; explicit cut reconstruction reports3 components total,2 leaf-bearing,1 leafless, whereas claiming all components leaf-bearing must fail.
8. Falsely favorable stability: C actual yR−y=1, claimed0 must fail exact flag comparator, and makes the candidate prediction0 falsely favorable if both flags overwritten0; cost1 comparator catches.

Every expected mismatch must produce a named exception or false comparator result; clean twin passes alongside. Failures are retained, never overwritten. One-shot checker is intentionally problem-local; it is not registered as a trusted toolkit oracle. All expectations are born here as hand deductions, and contact with this implementation burns them as future independent certification data.

## Bounded preregistered bank

Begin controls and n≤4 pilot. Enumerate all unordered rooted labelled binary shapes on 2,3,4 labels, all ordered input pairs, every ordered nonempty disjoint complete split X|Y, all matching original cut-edge representatives, and all cross-side representative choices, subject to run slices≤60s. Pilot limit=12 valid shape/split cases; measure both n3 and n4. Progress unit: completed shape-pair/ordered-split/edge-pair/representative record in JSONL, never CPU/liveness. Per-slice deadline is 50s with hard 60s external cap; atomic result row each completed record.

After measured n4 projection, run complete n≤4 bank in bounded slices if projected feasible. For n5 use a fixed index tournament only: tree-pair index `(i,j)` with i,j<105; candidates selected by `(17*i+31*j)%97==0`, plus diagonal i=j and reversed-index j=104−i. Process at most400 shape/split cases total, at most50s per run; first n5 pilot12 cases then write projection before enlargement. No n≥6 search. Variants: all registered control swaps, arbitrary Nat relabels `[17,103,1009,10007,99991]`, reversed input order, and swapped X/Y; values transformed from controls, not candidate-based expected retrofit.

Record every orientation bucket `(T_child_side,S_child_side)` in `{XX,XY,YX,YY}`, every stability pair `(0,0),(0,1),(1,0),(1,1)` plus invalid differences separately, all representative options tested/eligible, all valid AF crossing obligations checked, all marker-containing minimum blocks tested. A missing bucket is debt, never a theorem of impossibility. Exhaustive finite minima are test-oracle outputs, not algorithm steps.
