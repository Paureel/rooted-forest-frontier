# Prerelease design and postrelease plan

## Blind controls and independence

`EXPECTATIONS-v1.json` contains literal values written before code execution. The t1-public example was retrieved from the root target. The t2 and t3 trees are constructed here: S moves leaf1 above the caterpillar on the other labels, while T makes 0,1 a cherry. Removing singleton1 leaves the same caterpillar; full trees differ, so the optimum is exactly two blocks. For t3 singleton0 additionally forces at least three blocks because the remaining four-leaf trees disagree; singleton1 admits two; the pendant partition itself is a four-block agreement. These are manual construction expectations, not outputs from the future enumerator.

The fresh route assigns original address vertices, constructs undirected adjacency and obtains every minimal hull by explicit graph paths. It identifies outgoing original child edges and obtains components by graph deletion. Agreement checks unordered restricted topology plus disjoint graph hulls. It shares only the mathematical public definition with the uncontacted candidate. Restriction is independently implemented from selected leaves via pruned descendant structure. Partition enumeration is restricted-growth recursion and never candidate code. Candidate material is not used as oracle, tuning data, comparator, or controls. Every previously absent failure will be retained with an erratum before any revision.

## Tool choice

Read the toolkit index and full Gatekeeper guide. Gatekeeper parses AMFlow/oracle dumps and numerical fit certificates; neither it nor any index entry implements graph agreement forests or Lean stored producer occurrences. Fresh one-shot task-local code is justified both by the capability gap and this review's independence requirement. It is not a replacement toolkit package.

Stop at the frozen 120-second bound, preserve all failures, and make no universal inference from no counterexample. Progress units are completed tree pairs, agreements and per-claim checks written in the receipt. No long run is authorized by this plan.
