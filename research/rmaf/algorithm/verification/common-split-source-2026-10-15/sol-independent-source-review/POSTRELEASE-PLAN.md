8. Inventory compiler-only extraConstNames separately; a name without ConstantInfo is not a body-inspected scientific occurrence. If a theorem dependency needs such a body, stop at the explicit gap. Do not turn declaration counts into percentages of scientific acceptance.

## Representation and memory

The detector streams a JSONL record for one actual stored occurrence at a time. Each type/body/rule uses a tagged DAG; Names, levels, binders, literals, expression metadata, Syntax, SourceInfo, substrings and kind-specific semantic fields are explicit. Exact row/field hashes supplement original source/olean byte hashes. Cached Expr/Level bits and physical memory sharing are excluded and cannot support machine-code claims. Detector pointer memoization is audit infrastructure over retained raw ConstantInfo roots, never an unsafe scientific proof.

The current Python control harness deliberately holds its tiny fabricated rows for mutation tests. It must not be applied as a huge all-candidate raw-body map. For candidate work, process one producer at a time and store only compact occurrence keys and field hashes in a SQLite index; keep the lossless per-occurrence payloads on disk. Use a second sequential pass to validate same-producer private-view witnesses against that index. Set a32-MiB maximum JSONL record and50-second per-operation cap; an oversized record is an explicit scope failure requiring a separately versioned chunked extension and rerun of controls. First measure the released package's row/module sizes. Do not load a giant author map, infer omitted bodies, or copy another reviewer's code.
