# Prerelease freeze

READY binds only independent preparation before candidate contact. It is not a source-theorem or runtime verdict and authorizes no self-release. Root must inspect READY and issue an exact RELEASE naming immutable candidate bytes before further contact.

The final manifest hashes every retained file except the manifest and its digest file; the digest pins that manifest. Files are made read-only after creation. This is a local content-hash freeze, not independent timestamping. Future execution should copy the frozen scripts into a separately named postrelease/replay subtree and write new receipt paths. Do not overwrite the frozen controls, code versions, registries, failures or old X0 files.
