## Exact detector scope

The audit imports installed Lean as infrastructure; every fabricated scientific control imports only Std. For each requested scientific producer, read its actual stored ModuleData arrays from .olean parts in order, before name coalescing. Each occurrence records producer, part, index, structural name, ConstantInfo kind, universe parameters, exact type/body expression DAG, kind-specific metadata and recursor rule bodies, direct dependencies, all reachable axioms/unsafe/partial/missing names, and separately resolved module origin and resolved declaration representation. Check constNames against constants names and array lengths. Inventory extraConstNames separately, with an explicit no-ConstantInfo/uninspected-body limit.

Representation v1: tagged JSON arrays for names/universes/syntax/metadata; per-declaration expression DAG with integer child references, structural interning (binder names/annotations and metadata retained), type/body/rule root indices, and all semantic ConstantInfo fields. JSONL is streamed one occurrence at a time; Python hashes exact row/field bytes and compares records without loading a global raw-body map. Cached Expr/Level computed hash bits and memory sharing are excluded, as nonsemantic runtime caches; original olean bytes are independently hashed. Any unsupported constructor or missing requested module fails. Runtime path/source/olean/import lists are exact and pinned. Store each actual occurrence before examining resolved names.

Acceptable closure axioms are exactly propext, Classical.choice, Quot.sound. Direct scientific custom axioms always reject, including unused/private/coalesced ones; sorryAx and compiler-trust axioms reject. Unsafe/partial scientific declarations and unsafe proof dependencies reject. Source sorry/admit/native_decide tokens reject outside comments/strings by semantic closure plus source inspection; a string match alone does not establish a defect. Missing references or unresolved attribution reject. Compiler-only extras get a distinct inventory and cannot be counted as body-inspected declarations.
