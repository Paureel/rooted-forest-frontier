# Producer audit instrument

`ProducerAudit.lean` imports installed Lean as detector infrastructure, reads requested scientific producers' stored ModuleData arrays directly, and streams every occurrence before resolved-name coalescing. It records exact type/body/rule DAGs, structured names/levels/metadata, imports including all flags, closure axioms/unsafe/partial/missing references, and resolved origin separately. It preserves exported theorem-view stubs and qualifies them only through an exact actual private proof occurrence from the same producer. `check_controls.py` exercises the small fabricated fixtures and mutation comparators. `index_receipt.py` validates the same data sequentially and stores compact hashes/keys in SQLite.

Use this only with fixed source/build provenance and a root-released scientific package. It is not a theorem prover, an optimum solver, machine-code validation, a global raw-body map, or an extra independent replication of this agent's prior X0. Candidate use is barred until exact root RELEASE. The control harness keeps only tiny fabricated row sets; candidate bodies remain in per-occurrence disk receipts under the32-MiB row limit. Missing/unsupported/oversized data or attribution is a scope failure, not a clean result.

A clean detector result means only that the represented occurrences, allowed axiom closures and source/origin comparisons passed within the stated representation. Direct custom scientific axioms, including unused/private/coalesced ones, reject. Standard axioms allowed are exactly propext, Classical.choice, Quot.sound. Scientific unsafe/partial declarations or proof dependencies reject. Compiler-only extra names have no ConstantInfo body in that metadata and are inventoried separately. Cached runtime hash bits and physical sharing are excluded. Installed standard-library binaries are pinned trusted inputs, not rebuilt here.

Before trusting this instrument, run the frozen clean/hostile Std controls, false-proposition compilation diagnostic, same-name coalesced axiom plant, private/generated/unused cases, exact kind/type/body/import/origin/source/olean mutations, all encoder constructor/metadata round trips, and same-producer multipart proof-witness mutations. The retained v7/v2 executions passed these controls after documented repairs. Preserve all prior failed code/logs. Postrelease scope and exact module/source mapping are defined in `POSTRELEASE-PLAN.md`; semantic and consumer acceptance remain separate.
