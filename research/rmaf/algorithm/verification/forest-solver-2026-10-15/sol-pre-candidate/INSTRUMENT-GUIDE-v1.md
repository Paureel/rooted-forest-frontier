# One-shot prerelease review instruments

These instruments are deliberately local, problem-specific review tools. They are not new shared toolkit packages and do not implement the generic candidate solver. No production evaluator or other reviewer's implementation was copied.

`graph_partition_v2.py` constructs original-address adjacency graphs from literal trees, forms minimal hulls as unique graph paths, compares restricted rooted topology as induced clade sets, and enumerates set partitions by first-element insertion. Reach for it only for finite ForestState fixture checks at <=6 labels. Its outputs are exact Boolean/integer/Fraction values and measured case seconds. `plants`, `pilot`, and `battery` each write a structured receipt and exit nonzero on an unexpected mismatch; a named caught false twin is evidence that a detector fired, not a theorem refutation. Belief is limited to the frozen literal controls and finite denominator. `graph_partition_v1.py` is the preserved failed diagnostic formatter version.

`replacement_controls_v1.py` checks the literal fixture branches in EXPECTATIONS-v4-supplement.json against every valid final forest of the crossed and three-region cases. It checks actual restrictions, proper replacement, unchanged other sources, exact d+residual cost, ownership readout, all-forest coverage and returned-minimum selection. It does not predict the released source-core list or ordering. Seven corrupted twins must be caught.

`origin_audit_v2.lean` dynamically imports a root module in private mode, enumerates all constants, filters by actual imported module origin and records exact types, bodies (including opaque/theorem bodies), recursor rules, constructor/inductive metadata, direct dependencies, flags and standard-axiom closures. This is auditor tooling importing Lean; scientific toy modules import Std only. It does not inventory a namespace or just a queried theorem. Its JSON has per-environment module-origin counts so missing/private/query-only inventories fail even if their claimed record total is changed. It is not a kernel replacement or compiled-machine semantics proof. v1 is the retained namespace-qualification failure.

`toy_pilot_v2.py` times the same compile/audit path before the fixed `toy_battery_v2.py` battery. Each subprocess is capped at 30 seconds and every command/gate is retained. The battery proves that clean private/generated origins pass, unused/private custom axioms and missing/duplicate/body records are rejected, false Lean declarations fail to compile, and same-module import/body controls discriminate. v1 failures remain filed. `standard_axiom_control_v1.py` demonstrates the allowlist on actual Std terms using precisely propext, Classical.choice and Quot.sound, then catches sorryAx. `literal_adapter_control_v1.py` strengthens the adapter fixture to exactly one source-line change and demands exact equality of all 14 original scientific origin records, with no normalization; the body-only false twin must differ.

Run Python through `./bootloops-python`; Lean subprocesses use `bootloops-lean`. All work stays local. No large census or general toolkit suite is implied by these commands. The shared BootLoops validation suite is not run by this narrowly restricted arm; only this arm's specifically authorized instruments were executed. No unavailable engine is being silently credited.
