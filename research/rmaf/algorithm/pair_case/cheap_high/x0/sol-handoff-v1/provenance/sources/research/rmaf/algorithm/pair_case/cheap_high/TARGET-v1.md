## Actual setting

Ordinary rooted binary source S and target T have distinct identical original
leaf labels and no implicit rho. P=[A,B,C] is a proper original source
partition with vertex-disjoint unsuppressed minimal source embeddings. A and B
overlap in the target; C's target embedding is disjoint from both. An oriented
original target edge e divides A into nonempty A1,A2 and B into nonempty B1,B2.
The A sectors are disjoint from the whole B embedding and the B sectors are
disjoint from the whole A embedding (the public pair-case mutual-clear
condition, not merely local degree two). The claimed source cuts are literal
original edges. An already good parent means equality of its rooted source
and target restrictions. Being source-connected alone does not make it good.

Define the A-clear coloring on ALL original source leaves: A1,A2,B,C get four
different colors. Define B-clear symmetrically. The lists LA,LB are the actual
raw lists from the frozen CoreProgram.generate with these colorings and a
finite original cut budget q. Each emitted occurrence has its literal source
cut-list length d. Do not erase duplicates or count only selected branches.

## Candidate chain to attack

1. Four nonempty original colors and reviewed source-core semantics give
   d>=3 and raw sum(2^-d)<=1/8 for either list. If a list contains a cost-three
   occurrence, positivity then forces the literal list to contain exactly that
   ONE occurrence. Call this list cheap. Otherwise every output costs at least
   four, and the proposed bound is sum(c^-d)<=2/c^4 for every rational c>=2.
   A cheap output's four components should be exactly its four whole color
   classes, using original component count and proper partition, not an
   assumed prefix-profile grammar. Empty/pruned lists are high with zero mass.
2. If one parent is already good, a correctly supplied binary E exchange
   would permit retaining that parent and using only the other clear cover.
   Treat exchange as a CONDITIONAL premise here; its separate fresh review is
   running and is not an input to this X0. Test the conclusion independently
   on finite actual agreement partitions, without reading the E proof.
3. If both parents are bad and both lists are high, residual raw mass is
   <=4/c^4. If one list is cheap and one of its two whole cleared sectors is
   bad, the cheap branch should require at least one genuine further cut.
4. If a cheap A list has both A sectors good while A is bad, the actual
   two-sector source partition should witness that local A needs exactly one
   cut. Every B-clear output should leave that unresolved A contribution
   intact, even if it is not legal to assume A is a single output block.
   This last universal statement is a deliberate hostile test site: if false,
   record the actual split A output and score the true additional cost. Do not
   repair it by silently requiring A to be a clade or using an optimum oracle.
5. The proposed resulting residual envelopes are bounded by 4/c^4 for
   2<=c<=3. The intended total with the endpoint branches is 2/c+4/c^4 at
   c=233/100. This is still conditional until the exact recursive consumer,
   query procedure and work charging are proved. A lower bound on unavoidable
   extra cuts is not a proof of an efficient algorithm that discovers them.
