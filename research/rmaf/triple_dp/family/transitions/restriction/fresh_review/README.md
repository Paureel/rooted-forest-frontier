# Fresh finite restriction checker

This one-shot review instrument constructs actual live child restrictions from
finite binary-tree families, reconstructs the four transition kinds with tagged
indices, and checks an explicit index bijection preserving every support vertex.
It independently validates every finite family field and exact counts/costs/tolls.

Use it to replay the frozen restriction control battery. It is deliberately
independent of project evaluators and is not a general DP solver or universal
proof. Leaf values never replace index identities.

Run from the workspace root, choosing a new output directory:

```
./bootloops-python research/rmaf/triple_dp/family/transitions/restriction/fresh_review/run_controls.py --output research/rmaf/results/triple-family-transitions-restriction-fresh-REPLAY
```

Exit 0 means the original instrument passed all 23 declared groups and the
numeric-blind copied instrument failed exactly the required numeric controls.
Exit 1 or an exception is failure; missing cases or source-pin drift refuse the
run. Detailed JSON includes the clean/corrupt comparisons and all exact
reconstructed supports, index maps and arithmetic equations. The copied mutant
is intentionally broken and must not be used as a checker.

The known-answer gate includes all four transitions, parent-closed child-root
ownership, unused roots, equal labels, malformed families, numeric and support
corruptions, an out-of-premise raw incursion and two independently authored
hostile cases. The frozen source manifest precedes the pilot and full execution.
`WORK.md` records commands, verbatim output and limits; `PHASE1-SOURCE-PIN.json`
is the input pin; the original receipts are under the named result directories.

Change record, 2026-10-14: initial independent implementation; no prior toolkit
instrument implements this family interface, and code sharing would defeat the
fresh-verifier assignment. Kept local as a problem-specific review instrument.
