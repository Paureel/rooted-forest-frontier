# Source-work qualification

The computed plan enumerates literal original path pendants, tests actual
parent descendant-label membership and chooses the first two c-side arcs,
all b-side arcs except the terminal a arc, or the actual LCA address. Every
address stays in the original tree. The source/cut/partition/current physical
tree and paid cost move together under input-role swapping. Literal cost lists
retain typeII costs four and larger; no suppressed-edge union is substituted.

The proof of rawPlan_original_cover concerns original AF refinement. The
current-source partition/embedding theorem follows from actual original
splits. A separate paid+1 count and root-validity proof is still required at
currentGuard. The raw callback arithmetic is conditional on paid recursive
children and does not complete a budget-correct solver without that guard.

This release proves no extracted bit-operation, payload-size or whole-recursive
source-work bound. Original address comparisons, descendant-label lists,
filtering and copied partitions require an explicit cost model before such a
bound can be claimed. Finite Python control timing is instrument timing only.
It is not algorithmic acceptance or a scientific progress measure.

The isolated receipt binds pinned original source bytes, explicit import-name
adaptations, adapted bytes, fresh compiled producers and stored declaration
payloads under its recorded Lean runtime. Correspondence claims are limited
to these pins and that detector scope. The source/bit/payload qualification is
retained independently of mathematical compilation.

Final original cut recovery remains one separate operation on the selected
final AF. This package does not rerun, alter or silently replicate recovery
inside recursive children.
