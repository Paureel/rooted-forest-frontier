`admitted` retains original proper equal labels, the actual unordered selected
cherry, both earlier-rule orientations, both exact no-Rule4 guards, two source
cuts, both checked part embeddings, and exactly two good parts. The main
adapters assume no attachment, cover, exchange, split-saving or marked-solver
field. Generic graph and arithmetic lemmas expose their intermediate inputs;
the admitted adapters construct those inputs before using them.

`selectLocal_cases` proves every selected case's exact priority guards.
The operational theorem requires the selected constructor to differ from
`remaining`; that explicit scope restriction is the open Case3.2 obligation.
`local_prefix_checks` and `local_prefix_source_forest` derive cost two, three
checked permanent parts and the three executable original source restrictions
for every actual child in this selected prefix.

`Child` stores a permanent partition, source forest obtained by actual rooted
restriction, and paid original cut count. `ExactBoundedChild` is child-specific.
The release supplies no recursive solver. `pair_literal` and `pair_components`
derive the original pair-cut provenance and residual graph components.

The source of each imported completed module, its hash, any import-name
adaptation and the adapted hash are retained in STACK-PINS.json. The canonical
replay checks exact theorem interfaces and all stored producer occurrences.
