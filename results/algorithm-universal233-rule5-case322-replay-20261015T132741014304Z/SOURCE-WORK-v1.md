original descendant-edge splits. The paid count is exactly the length of the
stored original-cut list. The computed current guard checks nonroot validity,
distinctness, the current source partition and disjoint embeddings, and its
paid+1 component count. A type3(ii) branch with a,x,y retains all three cuts.
The callback list uses its actual paid count before subtracting from q, and
retains all successful occurrences in order.

The current Python control wrapper calls the frozen completed literal
materializer and ordinary AF evaluator. Both are development contacts. Its
finite inputs and mirrors establish no universal geometry, source-work or
novelty claim. No AF census is run in this arm.

For n original labels and m stored original cut addresses, the displayed Lean
partition materializer performs m cluster-label splits. Address lookup,
cluster label copying, list filtering and restricted-source reconstruction
must be charged when extracting a runtime bound. The code does not prove
bit-operation or payload-size bounds for these operations. The parent
package's earlier inspection estimates do not become a new extracted bound
by import. This arm supplies no whole recursive solver or whole source-work
recurrence.

The isolated final receipt checks a precise correspondence: pinned source
bytes, explicit import-name adaptations, adapted source bytes, compiled
scientific producers, and each stored declaration's type/body/reference
closure under the recorded Lean version. This correspondence is qualified by
those adaptations, the Lean runtime and detector scope. It does not prove a
compiled runtime bound or independent scientific acceptance.

Final original cut recovery remains a separate one-time operation on the
selected final AF. It must not be charged as a repeated hidden child step or
replaced by unioning cuts from suppressed displays. This package neither
reruns nor changes the completed final-recovery implementation.
