# Security and private material

Keep credentials, personal files, native runtimes and private access tokens out
of Git. The archive and collaboration remain private unless the maintainer
explicitly changes that policy. Contact Aurel Prosz (@Paureel) directly for an
access or credential incident; avoid pasting secrets into issues or discussions.

For ordinary reproducible code defects, use the bug/counterexample template.
The size and credential-pattern checker is a packaging aid, not a comprehensive
security review of the scientific archive or its external dependencies.
