## Operational derivation retained at the stop

The local allocation rules follow actual constructors independently of the bill: append allocates one new three-word cons per first-spine cell and shares the second spine; a flatMap allocates each returned head spine's append copies separately, even for equal payloads. Core combine copies its left output and refusal spines, then constructs retained receipt fields. Recursive activations allocate their actual live slots, with the printed fixed upper bound Fmax; no popped or discarded allocation is reclaimed. A global heap bound must sum decoder words, actual constructor-spine words, and all actual activation words before applying bit_length. Replacing that sum by current live data, unique returned payloads, or address width loses allocations.

For an independently proved allocated-word envelope H, every heap reference and pre/post heap frontier has width at most w(H+1), allowing the supplied fee table to be bounded after H is known. With a uniform successful-operation operand/address/result width W>=1, each elementary fee is at most 2+5W, directly from the WRITE row (the largest coefficient sum). The word-emission formula expands WRITE+CONST1+ADD and preserves repeated operands. These are local symbolic reductions of the released rules; no global H, W or elementary-operation polynomial has been established here, and no new composed numerical result is accepted without an executed check.

The noncircular proof order is structural actual invocations/candidates/spine cells and retained frames/metadata, then total allocation H and arithmetic value growth, then address/operand width W, then primitive operation counts and fee sum, then source occurrence/debit injection and the literal SOURCE bound. Using the desired RAM bill to infer H and then using w(H) to prove that same bill reverses this dependency and is inadmissible.

At the optimizer level, actual preflight includes properness plus Leaves/length even on improper decoded input. SCAN invokes each failed query and records its trial cell before unwinding; the successful trial is also recorded. The one successful finish invokes one recovery and retains its result and one recovery-list pair. The shared functional TYPE identifies the proper success budget with Q=k-1<N and the exact failed-trial order, conditional on the missing value/projection reconstruction. The source meter separately includes each trial's literal completeSourceCounter and fixed administration, plus preflight and one meterRecover work. An actual operation theorem must cover this complete sum; a bound on the successful trial alone cannot satisfy the consumer.
