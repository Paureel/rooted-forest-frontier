They do not mechanically validate arbitrary R derivations or prove graph determinism. The general graph-determinism result is the explicit fixed-input constructor induction in DERIVATION, using functionality supplied by the smaller-child semantic induction. The Phase A independent occurrence/order/rank/witness instrument remains the separate prior controls-first evidence. No expectation, script, output or passed run is changed or rerun by this clarification.

Likewise the Phase C bridge instances check exact integer inequalities at declared finite parameter values with arbitrary nonnegative P placeholders; they are not evaluations of the actual source meter/polynomial and do not establish a universal theorem by sampling.
